【1. Требования к окружению】
1. Windows 10 / 11
2. Установленный браузер Google Chrome (достаточно пути по умолчанию)
3. Установленный Python 3.10 или новее (при установке отметьте «Add Python to PATH»)
4. Сеть: включён прокси США (US) на этом компьютере либо шаблон прокси указан в левой части консоли

【2. Быстрый старт】
1. При первом запуске дважды щёлкните: 【1_首次运行_安装依赖并启动.bat】
2. В дальнейшем для повседневного запуска дважды щёлкните: 【2_启动控制台.bat】
3. Браузер автоматически откроет страницу консоли: http://127.0.0.1:8765

【3. Своя банковская карта для оплаты и запуск аккаунтов】
1. Укажите карту (обязательно):
   - В левой части веб-страницы, в блоке 【⚙️ Глобальные настройки】, укажите свою карту Visa или Mastercard:
     * номер карты (16 цифр)
     * срок действия (месяц / год, например 08 / 29)
     * код безопасности (CVC, 3 цифры)
     * имя держателя латиницей
     * безналоговый индекс по умолчанию уже заполнен 97201 (штат Орегон, США), менять не нужно
   - После заполнения нажмите 【💾 Сохранить настройки】.
   - Примечание: в скрипт встроена строгая защита от списаний — подписка оформляется только если в окне оплаты действительно указано US$0.00, списаний за весь цикл нет.

2. Массовый импорт аккаунтов Google:
   - В правой части веб-страницы, в блоке 【📥 Массовый импорт аккаунтов】, вставьте аккаунты (по одному в строке), поддерживаются любые форматы:
     * email----пароль----резервная почта
     * email----пароль----резервная почта----ключ 2FA
     * email----пароль----ключ 2FA
   - Нажмите 【➕ Импортировать аккаунты】.

3. Полностью автоматический запуск:
   - Нажмите 【▶ Запуск】 справа от аккаунта либо 【▶ Запустить все ожидающие аккаунты】 вверху страницы.
   - Скрипт автоматически выполнит:
     Шаг 1: вход в аккаунт Google и прохождение проверки через резервную почту / 2FA
     Шаг 2: привязка карты в окне оплаты + 1-й пакет 12 месяцев бесплатно (US$0.00)
     Шаг 3: наложение 2-го пакета, 6 месяцев бесплатно (US$0.00 -> 18 месяцев)
     Шаг 4: наложение 3-го пакета, 6 месяцев бесплатно (US$0.00 -> предел 24 месяца)
     Шаг 5: переход в Google Play и отмена автопродления, фиксация права на 2 года + скриншот-подтверждение
